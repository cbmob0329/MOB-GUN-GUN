# MOB GUN GUN — 草原 AREA 1-1

HTML / CSS / JavaScript のみで動く、横画面のラン＆ガンです。ビルドや外部CDNは不要です。既存の `denden/`・`atk/`・`stage/` を相対パスで参照しています。画像は複製・変更していません。

## 起動

GitHub Pages の公開元を、このリポジトリの対象ブランチ・ルートディレクトリに設定してください。`index.html` が入口です。ローカルでは任意の静的HTTPサーバーでリポジトリのルートを配信してください。

## 操作

| 操作 | スマートフォン横画面 | PC |
| --- | --- | --- |
| 左右移動 | 左下の任意の位置に触れてスティック操作 | A / D または ← / → |
| 歩行 / ダッシュ | 軽く倒す / 深く倒す | 通常移動 / Shift＋移動 |
| ジャンプ | JUMP | Space / K / ↑ |
| 射撃 | SHOOT、長押しで連射 | J、長押しで連射 |
| トリック・ザ・デンデン | SKILL 1 をタップ | 1 |
| サンダーボルト | SKILL 2 | 2 |
| デンデン・サンダー・バレット | SKILL 3 | 3 |
| 集合 / シールド・トランポリン | ピンクをタップ / ダブルタップ | クリック / ダブルクリック（Rも同様） |
| 一時停止 | 右上の Ⅱ | Esc または Ⅱ |

移動・ジャンプ・射撃は同時入力できます。縦画面では回転案内を表示して停止します。ブラウザで強制的な端末の向き固定はせず、横画面でプレイする設計です。別タブへの切替時も一時停止します。

## 実装

- `index.html`：HUD、スティック、操作ボタン、開始・一時停止・結果画面。
- `style.css`：16:9のゲーム領域、タッチ操作、縦画面案内、レスポンシブUI。
- `game.js`：120Hz固定ステップの物理処理、カメラ、各アニメーション、射撃、4種の敵、コイン、ゴール。
- `tests/game.test.cjs`：PC・スマホ横画面のブラウザ検証、タッチ同時入力、戦闘とステージ通しテスト。

調整値は `game.js` 冒頭の `CONFIG` にまとめています。歩行速度、ダッシュ速度、ジャンプ力、重力、連射間隔、弾速、弾ダメージ、最大HP、敵ごとのHP・接触ダメージ・移動速度を変更できます。

敵の描画は `drawEnemy()` に分離しています。敵画像を追加するときはこの関数の本体描画部分を差し替え、名前・HPバー・当たり判定をそのまま使用できます。

## スキル

### モブテツ

タイトル画面で「デンデン / モブテツ」を選べます。リトライ画面でも変更可能です。一時停止中はキャラ変更できません。モブテツ選択時は SHOOT が ATK に切り替わります。

| アクション | 操作 | ダメージ（敵1体あたり） | クールタイム |
| --- | --- | --- | --- |
| 通常攻撃1 | ATK / J | 18 | なし |
| 通常攻撃2 | 通常攻撃1中、または終了後0.22秒以内にもう一度ATK / J | 途中12＋着地16＝28（通常攻撃1込みで46） | なし |

| モブテツ一閃 | SKILL 2 / 2 | 突進36 ＋ 前方残像18、両方命中で54 | 9秒 |
| スキル3（名称未指定） | SKILL 3 / 3 | 96 | 14秒 |

- `tetsu.js` の `TETSU` にダメージ・クールタイムをまとめています。クールタイムは発動時から計測。一時停止で止まり、リトライ・キャラ変更でリセットされます。

### デンデン

通常射撃は8発で弾切れになり、1秒の自動リロード後に8発へ戻ります。射撃間隔は0.18秒から0.20秒へ変更しました。長押し中はリロード後に連射を再開し、ボタンを離してもリロード自体は進みます。残弾は画面右上、リロード残り時間はキャラの頭上に表示します。射撃中の移動速度は65％。8発目は雷ボムになり、半径75pxに18ダメージを1回与えます（通常弾は12）。リロード中も移動・ジャンプ・スキルが使えます。一時停止ではリロードも停止し、リトライで満タンへ戻ります。

- **トリック・ザ・デンデン（1）**：ワンタップで0.25秒の自動溜め→最大出力で発射。ボタンを離しても発射し、長押ししても連続発動しません。直撃120ダメージ、着弾地点から半径260pxの敵に72ダメージのシャボン玉大爆発。直撃相手へ爆風は重複せず、周囲の敵も各1回だけ命中します。クールタイム8秒。
- **サンダーボルト（2）**：`skill/86〜89.png`の大きな雷が前方210pxへ落下。着地時に60ダメージ＋1.2秒スタン。着地後は2秒間残り、中心で0.4秒ごとに12ダメージ、`skill/033〜036.png`の雷が左右へ連続して流れます。流れる雷は12ダメージ（同じ敵には0.35秒間隔以上）＋短いスタン。クールタイム12秒、発動後の操作ロックは従来どおり2秒。旧ランダム大量落雷は廃止。
- **デンデン・サンダー・バレット（3）**：`denden/033〜040.png`を余白除去・本体88px基準で表示。地面へ雷球を放ち、発動0.24秒後から0.13秒間隔で前方95 / 225 / 395pxの位置に3つの雷を出します。演出は確認済みの`skill/033〜036.png`を使用。大きさは115 / 175 / 245pxと順に大きくなり、ダメージは36 / 48 / 60。各雷は敵1体につき1回（範囲が重なれば最大144）。命中した敵は1.3秒の電撃・スタンと回転打ち上げ。左右両方向に対応し、足場・坂・橋の地面位置を参照します。クールタイム10秒。技同士の同時発動は不可、通常弾の残弾は消費しません。
- 一時停止で自動溜め・クールタイム・新技演出も停止し、再開で続きます。落下復帰で実行中の溜め・新技を中断、リトライ・キャラ変更で全リセットします。
- スキル1の最短クールタイム5秒・スキル2の最短9秒を将来の強化下限として維持しています。通常射撃・ジャンプ・2段ジャンプは従来どおりです。

草原は約21,800px。安全な導入、低い段差、任意の高所コインルート、徐々に増える敵、最後の耐久型の敵、ゴールで構成しています。封鎖広場を含む通しテストでは約100〜152秒。HPが0ならリトライできます。終盤にミラモブのボス戦があります。他AREA・ショップ・保存機能はありません。

### ミラモブ追加調整

髑髏の爆発は紫の炎・白紫の煙・衝撃波を伴い、半径130→330pxへ約0.2秒で広がります。0.4秒間の当たり判定を持ち、同じ敵には1回だけ本体ダメージ。操作版は本体140、貫通16、小髑髏14（8方向）。本体に当たると強く打ち上げます。ボス版の攻撃ダメージは従来値を維持。技中の軽減は通常攻撃には適用しません。

ボス戦ではピンクも通常攻撃・弾・爆風の対象になります。HPは減りませんが、攻撃・詠唱・シールドを中断し、通常0.75秒／強い攻撃1.15秒スタン、横と上への吹き飛ばしを受けます。0.65秒の連続被弾猶予を設け、スタン後は自律行動へ復帰。近くのピンクが攻撃していてプレイヤーが遠い場合、ボスはピンクにも向き直って反撃します。
