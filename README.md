# MOB GUN GUN — 草原 AREA 1-1

HTML / CSS / JavaScript のみで動く、横画面のラン＆ガンです。ビルドや外部CDNは不要です。既存の `denden/`・`atk/`・`stage/` を相対パスで参照しています。画像は複製・変更していません。

## 起動

GitHub Pages の公開元を、このリポジトリの対象ブランチ・ルートディレクトリに設定してください。`index.html` が入口です。ローカルでは任意の静的HTTPサーバーでリポジトリのルートを配信してください。

## 操作

| 操作 | スマートフォン横画面 | PC |
| --- | --- | --- |
| 左右移動 | 左下の任意の位置に触れてスティック操作 | A / D または ← / → |
| 歩行 / ダッシュ | 軽く倒す / 深く倒す | 通常移動 / Shift＋移動 |
| ジャンプ | JUMP | Space / K / ↑ |
| 射撃 | SHOOT、長押しで連射 | J、長押しで連射 |
| トリック・ザ・デンデン | SKILL 1 をタップ | 1 |
| サンダーボルト | SKILL 2 | 2 |
| デンデン・サンダー・バレット | SKILL 3 | 3 |
| シールド・トランポリン | モブピンクをタップ | ピンクをクリック / R |
| 一時停止 | 右上の Ⅱ | Esc または Ⅱ |

移動・ジャンプ・射撃は同時入力できます。縦画面では回転案内を表示して停止します。ブラウザで強制的な端末の向き固定はせず、横画面でプレイする設計です。別タブへの切替時も一時停止します。

## 実装

- `index.html`：HUD、スティック、操作ボタン、開始・一時停止・結果画面。
- `style.css`：16:9のゲーム領域、タッチ操作、縦画面案内、レスポンシブUI。
- `game.js`：120Hz固定ステップの物理処理、カメラ、各アニメーション、射撃、4種の敵、コイン、ゴール。
- `tests/game.test.cjs`：PC・スマホ横画面のブラウザ検証、タッチ同時入力、戦闘とステージ通しテスト。

調整値は `game.js` 冒頭の `CONFIG` にまとめています。歩行速度、ダッシュ速度、ジャンプ力、重力、連射間隔、弾速、弾ダメージ、最大HP、敵ごとのHP・接触ダメージ・移動速度を変更できます。

敵の描画は `drawEnemy()` に分離しています。敵画像を追加するときはこの関数の本体描画部分を差し替え、名前・HPバー・当たり判定をそのまま使用できます。

## スキル

### モブテツ

タイトル画面で「デンデン / モブテツ」を選べます。リトライ画面でも変更可能です。一時停止中はキャラ変更できません。モブテツ選択時は SHOOT が ATK に切り替わります。

| アクション | 操作 | ダメージ（敵1体あたり） | クールタイム |
| --- | --- | --- | --- |
| 通常攻撃1 | ATK / J | 18 | なし |
| 通常攻撃2 | 通常攻撃1中、または終了後0.22秒以内にもう一度ATK / J | 途中12＋着地16＝28（通常攻撃1込みで46） | なし |
| モブテツ流茄子落とし | 空中でATK / J | 30 | なし |
| MOB斬り | SKILL 1 / 1 | 12 × 3段 ＋ 最終48、全段命中で84 | 6秒 |
| モブテツ一閃 | SKILL 2 / 2 | 突進36 ＋ 前方残像18、両方命中で54 | 9秒 |
| スキル3（名称未指定） | SKILL 3 / 3 | 96 | 14秒 |

- 通常攻撃は押した瞬間に発動し、長押しで2段目は出ません。2回目の入力を予約できます。攻撃モーション中は自由移動・追加ジャンプを止めます。通常攻撃2は少し前進し、一閃は高速突進します。重力と着地処理は継続します。
- 通常攻撃2は差し替え後のHS/001〜006を使用。本体サイズを88px基準に調整し、約18pxだけ浮いて回転した後、実際の着地に合わせて006の着地斬りを表示します。最大約80〜95px前進しながら途中12・着地16の2ヒット（合計28）を与え、着地ヒットで敵を軽く前方・上方へ吹き飛ばします。各段は同じ敵へ1回までです。足場の上でもその足場に着地します。通常攻撃1は0.30秒・約42px前進、通常攻撃2はモーション時間を1.3倍速にしました。判定幅も通常攻撃1を115→130px、攻撃2を途中145→160px・最後155→170pxに広げています。
- 茄子落としはJS/004〜008と薄い紫の発光を使い、発動0.06秒後から最低1150px/秒で急降下します。実際に地面・足場へ着地した位置で紫の衝撃波と破片を表示。命中位置のSKILL/01〜04と上方向への吹き飛ばしも継続し、降下中と着地範囲で同じ敵への30ダメージを重複させません。
- MOB斬りはCS/001〜008と正面の大型SKILL/09〜12。09〜11にも各1回の判定を持ち、12で強く吹き飛ばします。途中の段で撃破した敵も最終段で吹き飛ばします。
- 一閃は650px以内の最も近い敵へ向きを合わせ、敵がいない場合は現在の向きへ突進します。HSP/001〜008とSKILL/05〜08、前方残像を表示。本体と残像はそれぞれ敵1体につき1回まで命中します。突進にも地形の衝突を適用します。
- スキル3はPS/001の後、002・003を0.05秒ごとに1秒間切り替え、004→005→006（0.4秒保持）→007→008。SKILL/13〜16とともに敵を回転させながら大きく打ち上げます。撃破した敵も着地まで飛行演出を残します。
- 通常攻撃・空中攻撃・スキルを含むモーション中は被ダメージ50％軽減（切り上げ・最低1）。スキル3の溜め中1.1秒間は半径相当230px以内・高低差150px以内の敵を継続スタンさせ、移動・接触攻撃・投球準備を止めます。効果中は星を表示します。
- `tetsu.js` の `TETSU` にダメージ・クールタイムをまとめています。クールタイムは発動時から計測。一時停止で止まり、リトライ・キャラ変更でリセットされます。
- 元画像は変更せず、読み込み時にアルファ境界を検出して余白を除いて描画します。`tetsuBody` の各フレームの本体範囲・足元・中心を使い、剣・斬撃・残像を含めず本体高さ88pxを基準に統一しています。JSの大きな余白にも同じ処理を適用します。
- `node tests/tetsu.test.cjs` でPC・タッチ操作、連撃、空中攻撃、左右の突進、各段のダメージ、複数敵への判定、撃破後の吹き飛ばし、クールタイム、一時停止、リトライとキャラ切り替えを検証します。実機での操作感は未確認です。

### デンデン

通常射撃は8発で弾切れになり、0.5秒の自動リロード後に8発へ戻ります。射撃間隔は0.18秒から0.20秒へ変更しました。長押し中はリロード後に連射を再開し、ボタンを離してもリロード自体は進みます。残弾とリロード残り時間を操作ボタン上に表示します。リロード中も移動・ジャンプ・スキルが使えます。一時停止ではリロードも停止し、リトライで満タンへ戻ります。

- **トリック・ザ・デンデン（1）**：ワンタップで0.25秒の自動溜め→最大出力で発射。ボタンを離しても発射し、長押ししても連続発動しません。直撃120ダメージ、着弾地点から半径260pxの敵に72ダメージのシャボン玉大爆発。直撃相手へ爆風は重複せず、周囲の敵も各1回だけ命中します。クールタイム8秒。
- **サンダーボルト（2）**：画面内に約3秒のランダムな落雷。1発60ダメージ。発動後2秒は移動・ジャンプ・通常射撃を停止し、重力・着地は継続。クールタイム12秒。
- **デンデン・サンダー・バレット（3）**：`denden/033〜040.png`を余白除去・本体88px基準で表示。地面へ雷球を放ち、発動0.24秒後から0.13秒間隔で前方95 / 225 / 395pxの位置に3つの雷を出します。演出は確認済みの`skill/033〜036.png`を使用。大きさは115 / 175 / 245pxと順に大きくなり、ダメージは36 / 48 / 60。各雷は敵1体につき1回（範囲が重なれば最大144）。命中した敵は1.3秒の電撃・スタンと回転打ち上げ。左右両方向に対応し、足場・坂・橋の地面位置を参照します。クールタイム10秒。技同士の同時発動は不可、通常弾の残弾は消費しません。
- 一時停止で自動溜め・クールタイム・新技演出も停止し、再開で続きます。落下復帰で実行中の溜め・新技を中断、リトライ・キャラ変更で全リセットします。
- スキル1の最短クールタイム5秒・スキル2の最短9秒を将来の強化下限として維持しています。通常射撃・ジャンプ・2段ジャンプは従来どおりです。

草原は約21,800px。安全な導入、低い段差、任意の高所コインルート、徐々に増える敵、最後の耐久型の敵、ゴールで構成しています。封鎖広場を含む通しテストでは約100〜152秒。HPが0ならリトライできます。ボス・他AREA・ショップ・保存機能はありません。

## モブミイラ

- `enemy/miira/wa/001〜008.png`で歩行、`at/001〜008.png`で投球、`do/001〜008.png`でダウンします。
- 10区間に各6体、計60体を追加。従来の27体と合わせて初期配置は87体です。さらに2か所の封鎖広場で合計96体が追加出現し、総数は183体です。初期の移動練習エリアは空け、画面周辺の敵だけAIを更新します。
- HP24、接触ダメージ2、土球ダメージ3。敵が多い前提の雑魚向け設定です。通常弾2発、モブテツの通常2段連撃、または通常攻撃2の途中・着地両ヒットで撃破できます。
- 距離65〜430pxで攻撃開始。構えを見せて約0.315秒後（004）に1球投げ、攻撃終了から3.2〜3.68秒待ちます。各個体の初回攻撃タイミングもずらしています。
- 土球はCanvasで土の塊・陰影を描き、重力による放物線で飛びます。プレイヤー・地面・足場に当たると砕けます。同時被弾には通常の無敵時間を適用し、画面外の弾や古い弾は破棄します。一時停止で止まり、リトライで全消去します。
- ダウン001〜007は各0.09秒、008は0.5秒点滅・フェードアウト。吹き飛ばされた敵は飛行中に消さず、着地後にダウンを進めます。吹き飛ばしで投球準備は中断します。
- 読み込み時にアルファ境界でトリムしたCanvasをキャッシュし、歩行・攻撃は本体高さ72pxで表示。ダウンは立ち状態を基準に倍率を維持するため、倒れた体や魂のエフェクトが不自然に拡大されません。元画像は変更しません。
- 調整値は`miira.js`の`MIIRA`と`game.js`の`CONFIG.enemies.miira`にあります。

## テスト

Playwrightを利用できる環境で `node tests/game.test.cjs` を実行してください。既定ではインストール済みMicrosoft Edgeを使用します。`BROWSER_CHANNEL=chrome` でChromeも指定できます。Playwrightがなければ開発用に `npm install --no-save playwright` で導入してください。ゲーム本体には不要です。

確認環境：Edge / Chromium 153、PC 1280×720、スマホエミュレーション844×390（タッチ・DPR 2）。実機Android / iPhone・Safariでの確認は未実施です。

確認済み：歩行、ダッシュ、しきい値のヒステリシス、左右移動、ジャンプ、移動ジャンプ、射撃、移動射撃、空中射撃、3点同時タッチ、タッチキャンセル、安定した足場着地、着弾、撃破、接触ダメージと無敵、コイン取得と演出の破棄、弾数制限、カメラ追従、ゴール、リトライ、ゲームオーバー、一時停止、縦画面案内。基本の移動・射撃回帰テストでは、ギミックを除いた専用のコース条件で検証しています。ギミックを含む現在の全ステージは`tests/route.test.cjs`で両キャラを検証します。

スキル確認済み：ワンタップ自動発射、直撃と広範囲爆風の重複防止、雷弾の3連・左右方向・回転打ち上げ、落雷の500％ダメージと重複防止、クールタイム、一時停止・リトライ。

追加検証：`node tests/tetsu.test.cjs` と `node tests/miira.test.cjs`。PC・スマホ相当のブラウザで、連撃の浮遊量・途中と着地のダメージ・足場への着地、一閃05〜08のみの再生、ミイラ60体配置、wa歩行、004投球、土球の上昇・命中・地形衝突、ダウン008の保持時間、吹き飛ばし中断、一時停止・リトライを確認しています。実機操作は未確認です。

## モブピンク

- デンデン・モブテツの両方へ同行する無敵のAI補助キャラ。通常は約65px後ろを歩き、プレイヤーのダッシュ・ジャンプ・2段ジャンプに追従します。段差は自動ジャンプし、穴へ落ちたり大きく離れた場合はプレイヤーの近くへ復帰します。
- プレイヤー付近の敵を優先し、近ければ`pink/09〜16.png`のシールドアタック。1回10ダメージ、攻撃間隔1.15秒、軽い吹き飛ばし。回復箱やコインは勝手に消費しません。支援中は攻撃・追従より踏み台を優先します。
- ピンクをタップ / クリック、またはRで**シールド・トランポリン**。確認済みの25〜32を2秒間ループし、「お助けするであります！」の吹き出しを表示。上から盾を踏むと1050px/秒の大ジャンプ。使用中の再入力では時間延長せず、終了後に再使用できます。
- 歩行01〜08、ダッシュ17〜24、ジャンプ33〜40。全40枚を読み込み時にトリムし、本体76px基準に調整。通常の歩行・攻撃・支援で余白に影響されないサイズにしています。
- `support.js`に画像処理、雷弾、状態異常、ピンクのAI・支援・描画をまとめています。ピンクはゲームの選択キャラではなく、常時同行する補助キャラです。
- ステージ上の「吊り橋」「崩れる床」等の説明ラベルと常時チュートリアル文は削除。包囲戦の残敵数や回復などの状態表示は維持しています。
- `node tests/support.test.cjs`でPC・スマホ相当のワンタップ新技、ピンクの直接タップ、追従・ジャンプ・攻撃・支援、技中軽減と溜めスタン、48体の全滅解除を検証します。`tests/route.test.cjs`ではピンクを有効にした通常の入力で両キャラの全ステージクリアを確認。他の単体戦闘テストはピンクを無効化し、プレイヤー自身のダメージを独立して検証します。
