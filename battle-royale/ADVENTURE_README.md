# MOB GUN GUN × BREAK BATTLE 冒険統合

現在の横スクロール配置は、[ラミ・舞台修正](UPDATE_TIMING_STAGE_JA.md)の専用レイアウトへ更新しています。以下の原典地形・穴・ロープ・障害物の記述は取り込み時点の記録です。原典データは保持していますが、現在の起動時には連続した地面、少数の箱、広い戦闘区間と高台を生成します。

## 現在の位置づけ
横スクロール冒険の追加実装です。既存の対戦・トレーニング・キャンペーンは残します。原作の戦闘プログラムをそのまま起動するものではなく、BREAK BATTLE のキャラクター・操作・技へ原作のエリアをつなぐ移植です。

v27のジェシー・テツ修正とラミ追加版を新しい統合コピーへ合流済みです。全20キャラの戦闘入力、ラミの青/白の描画と覚醒、冒険エリア終了時の状態解除を確認しました。原典と旧対戦版は変更していません。ブラウザ実機テストは未完了です。

## 共通戦闘向けに作り直した部分
- プレイヤーの移動、2段ジャンプ、近接・遠距離・必殺・投げ・ガードは BREAK BATTLE の既存 Fighter を利用。
- 敵の HP・速度などの元定義を参照しつつ、攻撃・ジャンプ・防御・飛び道具は共通エンジン用のアダプターで実装。原作と完全同一の挙動ではありません。
- ドラゴンの飛行・火炎弾・急降下、シャーティーのワープ・三方向弾、ボス部屋と増援を共通戦闘用に再構成。
- 通常難度の暫定HPはドラゴン300（原典1680）、ミラモブ300（1320）、シャーティー180（420）。原典HPはsourceHpとして別に保持。BRの実DPSに合わせた調整であり、原典値の再現ではありません。
- ドラゴンは10秒周期のうち飛行3秒、地上7秒。原典の長い飛行比率を変え、近接の反撃時間を確保。攻撃前0.55秒の予兆、攻撃後約2秒の次攻撃待ち。予兆と攻撃の見せ時間には移動を止め、反撃の間合いを作ります。シャーティーも予兆0.45秒を追加。
- 原典 miramob.js のボス部屋準備に合わせ、通常敵を部屋手前へ移動、部屋内の旧足場・プロップ・コインを整理。通常敵が戦闘部屋へ流入しないよう分離。増援撃破時に40%で回復アイテムを落とし、冒険ではプレイヤーのみ取得。
- ミラモブは BREAK BATTLE 側のキャラクター・技を使用。スライム／ミイラも既存 BR の画像表示を利用。
- 地形衝突、ロープの振り子、砂丘崩壊、タイヤ／岩の接触ダメージは新エンジン側で再実装。
- 壊せる原典の木・岩などは現段階で共通の箱表現へ置換。ロープ・コイン・砂丘・タイヤ・岩は簡易描画です。
- コインは共通技ゲージを回復。冒険専用セーブはエリア単位で、キャラ・世界・エリア・ボス選択を保存します。

## 実施した検証
- 20エリア生成、幅2400を越える移動、空中落下からHP半減復帰、勝利判定の分離、通常ゴール。
- 全20キャラ × 5戦闘アクションを冒険エンジンで実行。
- 5世界のボス出現、共通戦闘向けボスHP、原典値の保持、撃破前後の出口制御。
- 共通エンジン21項目、既存入力/複数タッチ/チャージ等、CPU42試合の回帰試験。
- 元画像と本番描画コードを NativeCanvas で描画。草原・各世界のボス・縦画面の画像を確認。
- 冒険開始・対戦メニュー復帰・選択ボスの続き保存を DOM スタブで検証。
- 敵有効の砂漠Area1をテツ/デンデン、Area4をテツの自動操作で開始からゴールまで通過（無敵化やHP書換えなし）。Area4の勝利→次の街Area1へ移行を実スクリプトで確認。
- 敗北→同エリア再挑戦でHPが戻ることを確認。遷移テストでは再現性のためプレイヤーHP1を設定後、実際の敵攻撃で敗北させています。
- 敵無効の経路試験で20エリアの出口へ到達。草原のロープ区間は自動操作で落下・復帰を繰り返すため、実操作の品質保証とは区別。

ブラウザは実行環境の制約で起動できず、上記の自動試験と画像確認を代替にしています。最終合流後に可能な範囲で再試験し、未確認を残したまま確認済みとは表示しません。

## 代表ボス戦の調整記録
通常HP・無敵なし、敵の攻撃有効、ボス部屋へ到達した状態からの自動操作比較です。人間による攻略評価ではありません。
- テツ近接主体（遠距離入力なし、間合いを詰めて通常/強/必殺）: 50.7秒でボス撃破、53.4秒で出口到達、残HP79。
- デンデン近接主体: 53.9秒でボス撃破、56.5秒で出口到達、残HP1。
- ニョロ遠距離だけを許す単純操作: 55.5秒でボス撃破、57.9秒で出口到達、残HP71。近接より大幅に速くはなく、被弾も22回発生しています。
全キャラ・全世界で同程度の難度を保証する試験ではありません。原典HP1680の直移植では極端に長期戦になったため、通常難度のドラゴンを300へ調整しています。
