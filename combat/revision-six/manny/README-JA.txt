再生契約
歩行：99 world px / cycle、基準速度 190px/s、0.521052632 秒。
ダッシュ：160 world px / cycle、基準速度 340px/s、0.470588235 秒。
距離位相は実際の移動距離 / 周期距離で進める。
位相 × clip総時間を frames[].duration の累積に渡してコマを選ぶ。
floor(phase*16) の固定均等選択では、この距離配分案は反映されない。
PC確認済み：通常再生は既に duration 累積対応。phaseStartsNormalized は現行コード未参照。
ただし walk↔dash 切替は floor(oldPhase*16) と固定対応表セル/16 のため、
統合時に「旧clipの累積durationから旧セル取得、新clipの対応セル累積開始へ移す」対応が必要。
phaseStartsNormalized は duration 正規化累積開始と完全に一致させてある。
この提案は世界移動速度を変えず、絵の表示境界のみを変える。
両向きとも固定 ground root。foot marker は診断専用で、body root / 物理 / 速度を補正しない。
全コマ authoredRootLift=0。身体全体の後付け上下揺れはない。
