モブラミ / Mob Rami — 16コマ以上版 ランタイム素材

内容
・通常25本、覚醒25本の完全な元シーケンス、身体合計896コマ。
・基本動作と独立した攻撃は16コマ。溜め開始16＋溜め維持16。
・各必殺技は連続32コマ。開始／攻撃中／着地・戻りは、その32コマ内のタイミング区間です。
・独立FXは12種類×16コマ＝192コマ。両フォームで共通の水・オーラFXです。
・弱1〜弱4、空中弱1〜弱3、最後の叩き落としは別の描画です。
・通常の承認済み歩行16コマを含みます。旧4／8コマ版は含みません。

画質と保存
ゲーム用は身体高さ220px基準へ空間的に縮小した別コピーです。WebP圧縮はロスレスですが、縮小そのものには画素情報の減少があります。
全フレームを維持し、外側の透明余白を切り詰め、8px間隔で配置しています。全テクスチャは静止ロスレスWebP、最大4096px以内です。
元の高解像度PNG／WebPマスター、承認済み歩行の元画像は変更せず別途保持しています。このランタイムZIPには高解像度アニメーションマスター全体は含まれません。承認済みモデル参照PNGはreferencesに収録しています。

読み込み
全ZIPを同じ場所へ展開してください。ルートcombat/hero-manifest.jsonが主人公専用です。他キャラのmanifestは上書きしません。
loadCartoonArt(pack, manifestURL)で読み込みます。BODYのキーにhero/は付けません（例:ranged、awakened-ranged）。FXだけhero/effects/を使います。
manifestのadapterはmanifestからの相対パス。adapter内src/frame.srcはadapterからの相対パスです。
エイリアスrangeは開始を含み、終了を含みません。必殺技の短い区間は独立した16コマ動作とは数えていません。

座標・タイミング
rect=[x,y,w,h]とpivot=[x,y]はランタイムテクスチャ上のpx。pivotはそのフレーム矩形内の座標です。durationは秒。bodyHeightはランタイムpxです。
身体移動はゲーム側で行います。画像に移動距離を焼き込んでいません。
releaseSocket、FXのdisplaySize/socketOffsetは表示身体高さに対する比率です。releaseFrameは0始まり。special2-activeでは3、rangedでは7です。
FXのdisplaySizeは呼び出し側sizeを完全に置き換えます。socketOffsetは既存アンカーへ加算。地面FXのY補正は既存の上方向アンカーを相殺するためです。
飛び道具FXはsocketOffset=[0,0]。rangedの原画方向は右0rad、水は下π/2rad。velocityモードはatan2(vy,vx)-nativeAngleRadiansで回転し、左右反転しません。splashはfixedです。

確認状態
元絵のコマ数・透明余白・重複ハッシュ・矩形・パス・静止ロスレスWebP形式を確認済み。
この版はゲーム実装への組み込み候補です。実機上の入力、当たり判定、接続、読み込み性能の確認は別途必要です。最新スマホゲームとしての完成品質・動作保証を示すものではありません。
細部の注意: 髪・飾りの描き換え差や、伏せ姿勢でMOB文字が小さく／一部見えなくなるコマは残ります。主要な攻撃軌道と反応のつながりは110px表示で別途確認しています。
